# UniBooks

## Biblioteca Universitária Compartilhada

Projeto Integrador — Engenharia de Software

O UniBooks é uma proposta de plataforma digital voltada para estudantes universitários, permitindo localizar e disponibilizar livros físicos e digitais por meio de empréstimo, troca, doação e venda.
